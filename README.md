# NLP Lab Work

This repository contains 10 practical programs implementing Natural Language Processing techniques, from basic text processing to advanced machine learning models.

## Programs Overview

### Program 1: Tokenization Techniques Comparison
- Implemented 10 different tokenization methods using NLTK, spaCy, TextBlob, and Keras
- Compared word tokenization, sentence tokenization, and specialized tokenizers
- Tested on sample text with contractions and emojis
- Analyzed differences in handling punctuation, special characters, and word boundaries
